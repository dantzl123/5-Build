# Indie Film Collective

Indie Film Collective is a four-page website where visitors can learn about independent film screenings, filmmaking workshops, and opportunities to collaborate with other creatives. The site uses a single-column layout on mobile and adjusts for larger screens.

## Pages

- Home (`index.html`)
- Film Screenings (`screenings.html`)
- Workshops (`workshops.html`)
- Collaborations (`collaborations.html`)
